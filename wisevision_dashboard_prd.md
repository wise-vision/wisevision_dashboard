## The following table details the functional requirements for the ROS 2 based WiseVision Dashboard.


| Requirement ID | Description | User Story | Expected Behavior/Outcome |
|----------------|-------------|------------|--------------------------|
| FR001 | Role-Based Access Control (RBAC) | As an admin, I want to manage user roles so that access permissions are appropriately assigned. | The system should allow admins to assign roles such as Admin, Operator, and Viewer. Admins have full access, Operators can view data without sending commands, and Viewers have read-only access. |
| FR002 | Real-Time Data Visualization | As a user, I want to view live data from ROS 2 topics to monitor robot status in real-time. | The dashboard should display real-time data streams from ROS 2 topics, supporting standard and custom message types. Visualizations should update dynamically as new data arrives. |
| FR003 | Historical Data Access | As a user, I want to access historical data to analyze past robot performance. | The system should store ROS 2 bag files and provide mechanisms to replay and visualize historical data for analysis. |
| FR004 | Custom Alarm Definitions | As a user, I want to define custom alarms based on logical expressions to monitor specific conditions. | Users should be able to create alarms using logical expressions applied to ROS 2 topic data. Alarms can trigger notifications via email, SMS, app alerts, and in-dashboard alerts. |
| FR005 | Map Integration | As a user, I want to see robot locations on a map to understand their geographical positions. | Integrate OpenStreetMap to display real-time and historical locations of robots. Users can track movements and analyze routes. |
| FR006 | Scalability for Multiple Devices | As a user, I want the dashboard to handle thousands of devices efficiently. | The system should be optimized for performance, ensuring responsiveness and reliability even when monitoring a large number of devices. |
| FR007 | User-Friendly Interface | As a user, I want an intuitive and visually appealing interface to interact with the dashboard easily. | Design a clean and simple UI with blue as the primary color. Ensure that navigation and data presentation are user-friendly and accessible. |
| FR008 | ROS 2 Bag Integration and wisevision data black box | As a user, I want to record and replay data using ROS 2 bag files and influxDB for analysis. | Provide functionality to record ROS 2 topic data into bag files / InfluxDB and replay them within the dashboard for historical analysis. |     
| FR009 | REST API Backend | As a developer, I want a REST API to interact programmatically with the dashboard's backend. | Expose a RESTful API that allows external systems to retrieve data, manage configurations, and perform other backend operations. |
| FR010 | Audit Logging | As an admin, I want to track user actions to ensure accountability and traceability. | Implement audit logging to record user activities such as logins, configuration changes, and command executions. Logs should be accessible for review. |
| FR011 | Deployment via Docker and Snap | As a user, I want to deploy the dashboard easily using Docker containers or Snap packages. | Provide Docker images and Snap packages for straightforward deployment on various systems, particularly edge servers. |
| FR012 | Unit and Integration Testing | As a developer, I want comprehensive tests to ensure the system's reliability and correctness. | Develop unit tests for individual components and integration tests for the overall system to validate functionality and detect regressions. |
| FR013 | Real-Time KPI Analysis | As a user, I want to monitor key performance indicators derived from ROS 2 topic data in real-time. | Calculate and display KPIs such as uptime, error rates, and performance metrics in real-time, updating dynamically as data changes. |
| FR014 | Periodic Reporting | As a user, I want to generate reports over specific time periods to analyze trends and performance. | Allow users to define time ranges and generate reports summarizing data, alarms, and KPIs for those periods. Reports can be exported in common formats like PDF or CSV. |
| FR015 | Command Dispatch via OpenAI API | As an admin, I want to send commands to robots through an integrated chat interface powered by OpenAI API. | Integrate OpenAI API to provide a chat interface where admins can input natural language commands, which are then translated into actionable instructions sent to robots. Only admins have access to this feature, ensuring controlled command dispatch. |
| FR016 | Customizable Dashboard Layout | As a user, I want to customize the layout of the dashboard to suit my preferences. | Users should be able to rearrange widgets, resize panels, and save their preferred layout for future sessions. |
| FR018 | Data Export Options | As a user, I want to export data in various formats for external analysis. | Allow users to export data in formats such as CSV, JSON, and XML for use in external tools or systems. |
| FR019 | User Notifications | As a user, I want to receive notifications for important events or alarms. | Implement a notification system that alerts users via email, SMS, or in-app notifications for critical events or alarms. |
| FR020 | Integration with WiseVision tools | As a developer, I want the dashboard to integrate with other WiseVision tools for a seamless experience. | Ensure compatibility and integration with existing WiseVision tools, allowing users to access and utilize data across platforms. |
